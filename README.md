# SQL & Log Analysis — QA Data Validation Project

QA portfolio project focused on SQL data validation, relational queries and command-line log analysis.

This project was completed as part of my QA Engineering training at TripleTen and demonstrates practical experience with SQL queries, relational data analysis and server log investigation.

## Project Scope

The project covered:

- SQL data validation
- Relational database queries
- Aggregations and filtering
- Grouping and ordering results
- Conditional data classification
- Table joins
- Date-based filtering
- Command-line log analysis
- HTTP error investigation

## SQL Tasks

The SQL work included:

- Counting records using `COUNT`
- Grouping results using `GROUP BY`
- Filtering grouped data using `HAVING`
- Sorting query results using `ORDER BY`
- Using `CASE` expressions for conditional classification
- Filtering records by date and time
- Joining related tables with `INNER JOIN`
- Validating expected data against query results

## Log Analysis

Command-line tasks included:

- Searching server logs with `grep`
- Filtering HTTP 400 and 500 responses
- Creating directories and output files
- Reviewing log samples with `head` and `tail`
- Counting log entries with `wc`
- Separating and organizing error logs for investigation
